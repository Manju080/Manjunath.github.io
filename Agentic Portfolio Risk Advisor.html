Platform Overview

The Agentic Portfolio Risk Advisor is a multi-agent LLM ecosystem designed for real-time quantitative risk modeling, financial news intelligence, and automated portfolio synthesis specifically tailored for Indian equities traded on the National Stock Exchange (NSE) and Bombay Stock Exchange (BSE).

Standard portfolio tracking tools rely either solely on mathematical metrics without situational context or provide loose unstructured LLM commentary prone to hallucinations. This project bridges that gap by establishing a decoupled architecture where pure deterministic quantitative models (Historical VaR, Sharpe Ratio, Beta) work in sync with Pinecone-backed Retrieval-Augmented Generation (RAG) news pipelines and Google Gemini LLM reasoning.

Core Engineering Achievements:

  • Decoupled Multi-Agent Architecture: Designed an agentic orchestration layer using LangChain and FastAPI that coordinates specialized autonomous agents (Price, Risk, News RAG, Memory) to perform structured analysis workflows.
  • Zero-LLM Deterministic Risk Engine: Implemented pure Python/Pandas mathematical modeling to compute 1-Day 95% Historical Value-at-Risk (VaR), annualized Sharpe Ratios, and Beta relative to the NIFTY 50 benchmark (^NSEI), guaranteeing 100% calculation accuracy without LLM hallucination risk.
  • Grounded News RAG Intelligence: Built an automated vector ingestion pipeline using Pinecone vector database with ticker-level namespaces, parsing and embedding financial news to deliver grounded 2-3 sentence summaries cited with verifiable sources.
  • Model-Agnostic LLM Factory & Session Memory: Created a flexible LLM provider factory supporting Google Gemini 2.5 Flash and Anthropic Claude, backed by SQLite conversational history tracking (SQLChatMessageHistory) to maintain context across multi-turn user interactions.
  • Production Web Dashboard: Developed a high-aesthetic, dark-themed Streamlit interactive UI featuring dynamic Plotly asset allocation donuts, VaR vs Beta risk scatter matrices, and INR currency formatting (₹ Rupees, Lakhs, Crores).

Orchestrator & LLM Factory

  • Sequential Pipeline Control: Manages step-by-step tool execution, passing raw portfolio inputs to sub-agents before synthesizing final output payloads.
  • Model-Agnostic Engine: Dynamically loads LLMs via the LLM factory module. Configured at temperature=0 with strict Pydantic JSON schemas to guarantee predictable, structured responses.
  • Hybrid Failover System: Incorporates an automated rule-based risk scoring fallback algorithm ensuring continuous functionality even if LLM API limits occur.

Quantitative Risk Agent

  • Historical VaR (95%, 1-Day): Computes non-parametric 5th percentile daily log returns over 1-year historical prices to quantify max expected daily portfolio loss.
  • Risk-Adjusted Sharpe Ratio: Calculates annualized excess returns normalized against daily volatility benchmarked over 252 trading days.
  • Benchmark Beta Modeling: Measures systemic risk by calculating daily return covariance against the NIFTY 50 index (`^NSEI`).

News RAG & Memory Agent

  • Pinecone Vector Indexing: Queries ticker-specific namespaces to retrieve top-matching financial news excerpts matching stock performance queries.
  • Grounded Summarization: Uses a tightly constrained prompt to generate 2-3 sentence summaries strictly bound to retrieved snippets without external speculation.
  • Conversational SQLite Memory: Persists user queries and AI recommendations via `SQLChatMessageHistory`, enabling multi-turn context retention.

Quantitative Financial Models

Historical Value-at-Risk (VaR)

Evaluates asset tail risk by computing daily log returns across 252 trading days. The 1-day 95% VaR identifies the threshold below which 95% of historical daily returns fall, representing the worst expected loss on a single trading day under normal market conditions.

Annualized Sharpe Ratio

Quantifies risk-adjusted return by scaling average daily returns and standard deviation to annual equivalents using the square root of 252 trading days scaling factor. Higher positive scores indicate superior compensation per unit of total risk incurred.

Systemic Beta vs NIFTY 50

Calculates asset sensitivity relative to broader Indian market movements. A Beta greater than 1.0 indicates higher volatility than NIFTY 50, whereas a Beta below 1.0 reflects a defensive asset with lower market sensitivity.

End-to-End Workflow

From a single user input to a fully synthesized, AI-powered risk report — here is exactly how the system processes each request across its multi-agent pipeline:

1

User Input via Streamlit Dashboard

The user opens the dark-themed Streamlit UI and enters their portfolio details — one or more NSE/BSE stock tickers (e.g., RELIANCE, TCS) along with the invested value (in INR) for each holding.

  • Tickers are auto-validated and NSE symbols are automatically suffixed with .NS for yfinance compatibility
  • A cold-start HTTP ping loop wakes the FastAPI backend if idle on a serverless instance
  • The request is serialized into a structured JSON payload and sent to the FastAPI endpoint
Streamlit UI → FastAPI REST API
2

Price Agent — Real-Time Market Data Fetch

The Price Agent is the first tool invoked by the Orchestrator. It calls yfinance to download 1 year of OHLCV (Open, High, Low, Close, Volume) historical price data for each submitted ticker.

  • Validates that all tickers return non-empty data — missing tickers are flagged as errors
  • Computes the current market price and calculates each holding's current INR market value
  • Returns a structured payload containing prices and portfolio valuations per stock
yfinance API → OHLCV DataFrame
3

Risk Agent — Quantitative Risk Modeling

The Risk Agent receives the historical price data and runs three pure Python/Pandas deterministic financial models — with zero LLM involvement to guarantee mathematical accuracy.

  • Historical VaR (95%, 1-Day): Computes daily log returns, then takes the 5th percentile as the worst-case daily loss threshold
  • Annualized Sharpe Ratio: Scales mean daily return and daily volatility to annual equivalents using the square root of 252 trading days
  • Beta vs NIFTY 50: Downloads NIFTY 50 (^NSEI) data and calculates the covariance of stock returns against index returns to measure market sensitivity
Pandas NumPy Math → Risk Report per Ticker
4

News RAG Agent — Pinecone Vector Intelligence

The News Agent queries a Pinecone vector database for each ticker to retrieve semantically relevant recent financial news — grounding the LLM's output in verifiable real-world events.

  • Each ticker has its own namespace in Pinecone, pre-populated with embedded financial news articles
  • A semantic similarity search retrieves the top matching news excerpts for the stock's performance context
  • A tightly constrained prompt instructs the LLM to generate a 2–3 sentence summary strictly from retrieved snippets — no hallucination
  • Source citations are included with every news summary for verifiability
Pinecone Vector DB → Grounded News Summaries
5

Orchestrator — Gemini LLM Synthesis

The Orchestrator collects all outputs from the Price, Risk, and News agents and passes them to Google Gemini 2.5 Flash for final synthesis.

  • Gemini is configured at temperature=0 with a strict Pydantic schema to produce a structured, predictable JSON report
  • It generates an overall portfolio risk classification (Low / Medium / High), a narrative summary, and per-stock insights
  • A rule-based fallback algorithm automatically classifies risk if the LLM API quota is exceeded
  • Conversation history is persisted in SQLite so users can ask follow-up questions in the same session
Gemini LLM → Structured Risk Report JSON
6

Dashboard Rendering — Visual Output

The structured risk report JSON is returned to the Streamlit frontend and rendered as an interactive, dark-themed dashboard with rich data visualizations.

  • Asset Allocation Donut Chart: Portfolio distribution by market value in INR
  • VaR vs Beta Scatter Matrix: Plotly scatter plot mapping each stock's daily risk against market sensitivity
  • Risk Classification Badges: Color-coded Low / Medium / High risk labels per holding
  • AI Narrative Panel: Full Gemini-generated portfolio commentary displayed alongside quantitative metrics
  • News Intelligence Panel: Per-stock grounded news summaries with source links
Plotly Charts → Streamlit Dark Dashboard
